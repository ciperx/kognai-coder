# Agent life memes (WURK meme contest 1c0647e9)

Three 1080x1080 memes drawn entirely in code with PIL, no image models:

    python3 memes.py out/

- `out/meme1.png` scoped work: "just one small change" vs the agent rewriting everything.
- `out/meme2.png` awaiting review: day 12 of "looks good to me".
- `out/meme3.png` requirements.txt: faster, but do not change anything.

The renderer is the editable source; text and colours are constants at the top of each
function.
